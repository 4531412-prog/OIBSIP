# Retail Sales Exploratory Data Analysis

## Oasis Infobyte Data Analytics Internship

### Level 1 — Task 1: EDA on Retail Sales Data

## Project Overview

This project performs exploratory data analysis on a retail sales dataset to identify sales trends, customer behaviour, demographic patterns and product performance.

Python was used to inspect, clean, analyse and visualise 1,000 retail transactions.

## Dataset

The dataset contains 1,000 retail transactions with information including:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

The project includes:

- Initial data inspection
- Data type validation
- Missing value analysis
- Duplicate detection
- Descriptive statistics
- Retail performance KPIs
- Monthly sales analysis
- Quarterly sales analysis
- Customer gender analysis
- Customer age analysis
- Age-group segmentation
- Product category revenue analysis
- Product sales-volume analysis
- Average transaction analysis
- Correlation analysis
- Scatter plot analysis
- Business recommendations

## Key Results

- Total Revenue: 456,000
- Total Transactions: 1,000
- Total Units Sold: 2,514
- Average Transaction Value: 456
- Best Sales Month: May 2023
- Best Quarter: Q4 2023
- Highest Revenue Product Category: Electronics
- Highest-Selling Product Category: Clothing
- Highest Revenue Age Group: 45–54

## Key Business Insight

Electronics generated the highest overall revenue while Clothing generated the greatest sales volume.

This demonstrates why product performance should be evaluated using both revenue and quantity rather than relying on only one metric.

The 45–54 customer segment also generated the highest revenue among the analysed age groups, indicating an important target segment for customer retention and promotional strategies.

## Business Recommendations

1. Maintain adequate inventory and marketing support for high-revenue Electronics products.
2. Use Clothing as a high-volume category for promotions and cross-selling opportunities.
3. Develop targeted retention and promotional strategies for the 45–54 customer segment.
4. Incorporate monthly and quarterly sales patterns into inventory and staffing decisions.
5. Evaluate product performance using revenue, sales volume, pricing and transaction value together.
